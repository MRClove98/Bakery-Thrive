# Bakery-Thrive
Bakery Thrive is an AI-powered bakery planning tool that helps you choose what to sell, set smart prices, estimate costs and profits, build your menu, and simulate your business. Enter your location and bakery details—or upload Excel data—to get tailored product and pricing recommendations.

# 🥐 Bakery Thrive

**AI-powered bakery planning, pricing, product recommendation, and profitability simulator.**

Bakery Thrive is a standalone web application designed to help aspiring bakery owners plan a bakery from the ground up. Enter your bakery location, business type, budget, target customers, operating costs, and product preferences to explore recommended products, pricing, profitability, menus, and business scenarios.

You can also **upload your own Excel or CSV spreadsheet** containing bakery products and prices. Bakery Thrive uses the imported information as its reference dataset for product recommendations and planning.

> **Important:** Bakery Thrive provides estimates and planning assistance. Its recommendations are not guarantees of business success, sales, revenue, or profitability. Real-world results depend on location, competition, demand, suppliers, rent, staffing, seasonality, customer behavior, and many other factors.

# 📂 How Importing Works

When you select a spreadsheet:

1. Bakery Thrive reads the file.
2. The first worksheet is selected.
3. Spreadsheet rows are converted into data records.
4. The application attempts to identify the relevant columns.
5. Product information is extracted.
6. Prices are converted into numeric values.
7. The built-in reference dataset is replaced with the imported dataset.
8. Product recommendations are regenerated.

---

# 🧠 Automatic Column Detection

Bakery Thrive attempts to recognize common column names.

For example:

```text
Name of Bakery
Category
Product Name
Average Price THB
```

can be interpreted as:

```text
Bakery → Name of Bakery
Category → Category
Product → Product Name
Price → Average Price THB
```

The application also attempts to recognize simpler alternatives such as:

```text
Bakery
Product
Price
```

---

# 📊 Recommended Spreadsheet Format

For maximum compatibility, use a structure similar to:

| Name of Bakery | Category | Product Name | Average Price THB |
| -------------- | -------- | ------------ | ----------------: |
| Example Bakery | Bread    | Sourdough    |               180 |
| Example Bakery | Pastry   | Croissant    |                90 |
| Example Bakery | Cake     | Cheesecake   |               150 |

The first row should contain column headers.

---

# 📄 Example CSV

```csv
Name of Bakery,Category,Product Name,Average Price THB
Example Bakery,Bread,Sourdough,180
Example Bakery,Pastry,Croissant,90
Example Bakery,Cake,Cheesecake,150
```

---

# ⚠️ Spreadsheet Import Notes

For best results:

* Use a clear header row.
* Keep product names in one column.
* Keep categories in one column.
* Keep prices numeric.
* Avoid merged cells.
* Avoid complicated multi-row headers.
* Avoid putting multiple products into one cell.
* Use the first worksheet for the main dataset.

# 🧮 Core Calculations

## Total Product Cost

A basic product cost can be represented as:

```text
Total Product Cost
=
Ingredients
+
Packaging
+
Allocated Labour
+
Other Variable Costs
```

---

## Gross Profit

```text
Gross Profit
=
Selling Price
-
Product Cost
```

For example:

```text
Selling Price = ฿100
Product Cost = ฿40

Gross Profit = ฿60
```

---

## Profit Margin

```text
Profit Margin
=
Gross Profit ÷ Selling Price × 100
```

Example:

```text
฿60 ÷ ฿100 × 100
=
60%
```

This is a simplified gross margin calculation.

# 📍 Break-Even

Break-even represents the point at which estimated revenue covers estimated costs.

A simplified contribution-based calculation can be expressed as:

```text
Break-Even Units
=
Fixed Costs
÷
Contribution Per Unit
```

where:

```text
Contribution Per Unit
=
Selling Price
-
Variable Cost Per Unit
```

Actual bakery break-even analysis can be more complicated because bakeries often sell many different products.

# 🛠️ Troubleshooting

## Excel upload does not work

Check that:

* The file is `.xlsx`, `.xls`, or `.csv`.
* The spreadsheet contains a header row.
* The first worksheet contains the dataset.
* Product names are present.
* Prices are numeric.

---

## Imported products look incorrect

Check your spreadsheet columns.

Recommended:

```text
Name of Bakery
Category
Product Name
Average Price THB
```

Avoid complex merged headers.

---

## Prices are not recognized

Make sure prices are stored as numbers rather than complicated text.

Good:

```text
180
```

Potentially problematic:

```text
฿180 per item
```

---

## The application looks different on another device

Bakery Thrive is responsive, but browser rendering can vary.

Try:

* Updating your browser
* Refreshing the page
* Using Chrome, Safari, Edge, or Firefox
* Checking browser zoom

# 🧠 Design Philosophy

Bakery Thrive is built around five principles:

## 1. Simplicity

Business planning should not require advanced financial knowledge.

## 2. Transparency

Estimates should be clearly presented as estimates.

## 3. Flexibility

Users should be able to replace the built-in dataset with their own research.

## 4. Experimentation

Users should be able to test different scenarios before committing real money.

## 5. Data-driven planning

Product and pricing decisions should be supported by data wherever possible.
